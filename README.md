# 🎨 Paint Clone

A simple and interactive browser-based drawing tool built with **Next.js** and **Tailwind CSS**. It allows users to draw on a canvas using a brush or eraser, change brush sizes and colors, and clear the canvas with a single click.

## 🚀 Features

- 🖌️ **Brush Tool** – Draw freely with customizable size and color  
- 🧽 **Eraser Tool** – Erase parts of your drawing seamlessly  
- 🌈 **Color Picker** – Choose any color for your brush  
- 📏 **Size Control** – Adjust brush thickness from 1px to 50px  
- 🔄 **Clear Canvas** – Reset your canvas with one button click  
- ✨ **Responsive UI** with vibrant styling using Tailwind CSS
